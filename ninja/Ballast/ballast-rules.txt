# -- Apex Trader Funding (4.0, effective 1 March 2026) ------------------------
# EVALUATIONS AND FUNDED (PA) ACCOUNTS DIFFER, AND IT MATTERS.
#
# Apex's help centre: on a Performance Account the intraday threshold "stops
# increasing" once it reaches Starting Balance + $100. On evaluations it does
# NOT work that way - Tradovate evaluations trail "indefinitely with the Peak
# Balance and do not stop", and Rithmic/WealthCharts evaluations stop at a
# different, higher level.
#
# So every EVALUATION row below carries LOCKAT 0, meaning Ballast keeps trailing
# the floor forever. On a Rithmic eval that understates your cushion slightly.
# That is the direction to be wrong in: assuming a lock that is not there would
# tell you that you have thousands more room than you do.
#
# 4.0 accounts only go up to 150K. If you hold a 75K, 250K or 300K it is a
# LEGACY account - see the legacy section below, whose drawdowns come from Apex's
